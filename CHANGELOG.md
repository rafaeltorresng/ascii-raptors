# Changelog

## Unreleased

This is the first prepared Git history of the existing local prototype, not a reconstruction of past releases. The package's existing `1.0.0-rc.1` version has not been tagged or published to npm.

- Three original articulated models: swallow-tailed kite, golden eagle and peregrine falcon.
- Five-bird sky, with bald eagle and California condor appearances based on the golden-eagle model.
- Procedural routes, coordinated banking, gliding and wingbeat transitions.
- Canvas ASCII rendering with stable material texture and opaque sky-compositor interiors in both themes.
- Light/dark themes, pause controls, reduced-motion handling and individual study tools.
- Numerical and frozen-reference tests, manual browser harnesses, lint/typecheck/build tooling and a GitHub Actions verification workflow.
